# Переходы состояния: переключение `with_salary`

## Выбранный срез

Один конкретный тип изменения — действие `ru.hh.applicant.feature.search_vacancy.filters.domain.interactor.a.o0`, которое reducer связывает с меткой `with_salary`. Это подтверждённый участок reducer-а, но начало в Compose не удалось соединить с этим сообщением. Поэтому это не заявляется как полностью восстановленный клик-путь.

## Подтверждённый переход

1. Reducer получает текущее `SearchFiltersFeature.c` и результат `SearchFiltersFeature.a`. Для `a.C1116a` вызывает специализированный `a(state, C1116a)`. `ev_aa14426a56fe532852a240d128fc5edcc625222bd011264948240427cb4fa9d4`.
2. В специализированном reducer-е вложенный `a.o0` учитывается как смена метки `with_salary`. Тип события аналитики выбирается по текущему `khe.p`: если `false`, `APPLY`; если `true`, `RESET`. Затем вызывается analytics sink. `ev_c788a71c03c99d1d3a92c3940ab98b602b2414a966d261122999f9bb2ee65c42`.
3. Reducer возвращает новое `SearchFiltersFeature.c`, формируя новый payload через `SearchFiltersStateInteractor.b(currentState.a)`. Следовательно, содержимое перехода состояния делегировано state interactor-у; точная модификация salary flag и значение `p` отдельно не декомпилированы в этом срезе. `ev_c788a71c03c99d1d3a92c3940ab98b602b2414a966d261122999f9bb2ee65c42`.

## Ограниченные переходы вокруг сценария

- `Bootstrapper.invoke()` выдаёт начальное `d.e`; `Actor.invoke(state,d.e)` вызывает `SearchFiltersInitInteractor` на основе входных/сохранённых параметров и преобразует результат в feature output. Последующая доставка к reducer выводится из ролей и сигнатур, но внутренний store не был полностью восстановлен. `ev_4a05c123592166f9b9bf24f7c1fad529d06eb8a7c77c1797276d3a7f05d71315`, `ev_36dc75d8df4cdf323ef7f782d8d213cea9e512820cdbb1e8e68eb3c56daefbc0`.
- Для `d.m` actor проверяет начальное состояние, затем эмитит событие для обновления количества вакансий; это соседний эффект, а не доказанный эффект переключения зарплаты. `ev_36dc75d8df4cdf323ef7f782d8d213cea9e512820cdbb1e8e68eb3c56daefbc0`.
